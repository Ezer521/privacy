EzVibe 隐私政策

生效日期：2026-10-09 ｜ 适用版本：3.5.0 及以上

一句话版本：EzVibe 完全在本地运行，不联网上传任何数据，没有账号体系。
In short: EzVibe runs entirely on your device. It never uploads any data, and has no accounts.

1. 我们收集什么

什么都不收集。EzVibe 没有遥测、没有广告 SDK、没有崩溃上报，也不向任何服务器发送您的任何数据。不存在把您的任何数据传输给我们或第三方的情况。

We collect nothing. EzVibe contains no telemetry, no ads, no crash reporting, and never transmits any of your data to us or to third parties.

2. 它与哪些设备通信（局域网设备控制）

EzVibe 的核心功能是把本机 AI 工具的工作状态反映到您自己家中的智能设备上。它与米家中枢 / Home Assistant 之间的通信全部发生在您的家庭局域网内，是设备控制指令（开关灯、调色温等），不是数据上传；通信内容只含设备控制指令与状态。

EzVibe reflects your local AI tools' working status onto your own smart devices at home. All traffic to your Xiaomi hub / Home Assistant stays inside your home LAN and consists of device-control commands (light on/off, color temperature, etc.) — never data uploads.

3. 本地存储的数据

应用只把以下内容保存在您自己的电脑上（%LOCALAPPDATA%\EzVibeFlutter\）：

  • 设置与凭据 —— 您配置的中枢/HA 连接信息，使用 Windows DPAPI 按当前用户加密后存储；
  • AI 状态文件 —— 供 EzAway 等同家族工具读取的当前状态；
  • 运行日志 —— 仅本机排障用，不含个人内容。

删除该文件夹即彻底清除全部数据，卸载应用同理。

Only your settings, the AI status file, and local logs are stored on your own device under %LOCALAPPDATA%\EzVibeFlutter\. Connection credentials are encrypted per-user with Windows DPAPI. Delete the folder to erase everything; uninstalling does the same.

4. AI 状态钩子（可选、需您主动安装）

若您想让 AI 工具（Codex / Claude Code / Cursor 等）的状态驱动灯光，需要在应用内主动安装对应的状态钩子。钩子只做一件事：在本机写入一个状态文件供 EzVibe 读取。它不联网、不采集代码或文件内容。

If you want AI tools (Codex / Claude Code / Cursor, etc.) to drive your lights, you opt in by installing a status hook per tool from inside the app. The hook only writes a local status file for EzVibe to read. It has no network access and never collects code or file contents.

5. 开机自启

微软商店版的「开机自启」通过 Windows 标准的启动任务（StartupTask）实现，默认关闭；您可以随时在「任务管理器 → 启动应用」中开关。

The Store version's optional autostart uses a standard Windows Startup task (off by default), toggleable anytime in Task Manager → Startup apps.
