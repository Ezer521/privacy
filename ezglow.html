EzGlow 隐私政策 / Privacy Policy

2026-09-17 · 适用于 EzGlow（微软商店版与绿色版）

一句话结论 TL;DR

EzGlow 不收集、不上传任何数据。 所有功能都在你的电脑本地完成，没有任何网络通信用于数据收集。

EzGlow does not collect or upload any data. Everything runs locally on your PC; there is no network communication for data collection.

1. 屏幕画面（抓屏）的用途 Screen capture

EzGlow 的玻璃拟态界面会读取你屏幕上本窗口身后的画面，仅用于在本地计算背景模糊效果。该画面不保存到磁盘、不缓存、不上传、不发送给任何第三方，模糊计算完成后立即丢弃。

The frosted-glass UI reads the screen area behind its own window, solely to compute the background blur locally. The captured pixels are never saved, cached, uploaded, or shared; they are discarded right after the blur is computed.

2. 亮度调节 Brightness control

变暗通过 Windows 标准显示 API（Gamma Ramp / DDC/CI）写入显示器。这属于本地显示控制，不涉及任何数据传输。

Dimming writes the display via standard Windows APIs (Gamma Ramp / DDC/CI). This is local display control; no data is transmitted.

3. 存储在本机的数据 Local data

  • 设置（语言、空闲等待、亮度等）保存在本机 %LOCALAPPDATA%\GentleDim；
  • 运行日志保存在同一目录的 logs 子目录，仅用于排查问题；
  • 以上数据不会被程序主动上传。卸载并删除该目录即完全清除。

说明：目录名沿用早期内部代号 GentleDim（应用显示名后来改为 EzGlow）， 两者不一致是有意保留的 —— 改名会让老用户已保存的设置全部读不到。

可选的「开机自启」默认关闭：微软商店版由 Windows 的「设置 → 应用 → 启动」统一管理，绿色版写入您用户自己的 Run 注册表项，两种形态都可随时取消。

Settings and logs are stored locally under %LOCALAPPDATA%\GentleDim and are never uploaded. Uninstalling and deleting that folder removes everything. The folder keeps its original internal codename GentleDim (the display name was later changed to EzGlow); the mismatch is intentional, since renaming it would orphan existing users' saved settings. The optional "start with Windows" is off by default: the Microsoft Store edition uses the standard Windows Startup-apps setting, while the direct-exe edition writes to your own user Run key; both can be turned off at any time.

4. 网络访问 Network access

EzGlow 没有任何联网功能：不上传遥测、不检查更新、不请求任何网页。

EzGlow has no networking features: no telemetry, no update checks, no web requests.
