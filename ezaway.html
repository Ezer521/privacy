EzAway 隐私政策

生效日期：2026-09-23 ｜ 适用版本：3.4.x 及以上

一句话版本：EzAway 完全在本地运行，不联网、不上传任何数据，没有账号体系。
In short: EzAway runs entirely on your device. It has no network access, uploads nothing, and has no accounts.

1. 我们收集什么

什么都不收集。EzAway 没有遥测、没有广告 SDK、没有崩溃上报、不请求任何网络权限，也不含任何联网代码。不存在把您的任何数据传输到服务器或第三方的情况。

We collect nothing. EzAway contains no telemetry, no ads, no crash reporting, and no networking code of any kind. Nothing is ever transmitted to us or to third parties.

2. 屏幕抓取（玻璃效果）

EzAway 的毛玻璃界面需要知道窗口背后是什么颜色。应用用 Windows 标准的屏幕拷贝接口抓取窗口背后的一小块屏幕区域，仅在内存中做本地模糊计算后作为背景显示。该画面不保存到磁盘、不上传，窗口隐藏或关闭即释放；窗口被其他窗口遮挡时连抓取都不会发生。

The frosted-glass UI captures a small region behind the window via standard Windows screen-copy APIs and blurs it locally in memory, for display only. It is never saved or uploaded, and is released when the window is hidden or closed. Nothing is captured at all while the window is occluded.

3. 自动关机（核心功能）

EzAway 会在「您主动开启监控」且「它判定您已离开电脑并持续达到您设定的时长」之后，执行一次本地电源操作（相当于点击「开始 → 关机」，不强制关闭任何应用）。判定依据是多项 Windows 本地信号的综合评分 —— 包括显示器电源状态、屏幕锁定状态、键盘鼠标无操作时长、以及 Windows 自己判定的用户活跃状态等；其中只要键盘或鼠标在最近 5 秒内有过操作，就一律判定为您仍在电脑前，不会开始倒计时。这是完全在本机发生的操作：

  • 监控必须由您亲手开启（或您在设置中明确打开「启动后自动监控」）；
  • 开启监控时应用会再次明确告知判定规则与取消方式；
  • 界面常驻显示当前判定状态与判定理由（例如「你还在电脑前」或「判定为你已离开」，并列出各项证据分数），您随时可以看到它为什么这样判断；
  • 关机前有缓冲期（默认 30 秒，可调 10–600 秒），期间弹出通知，动一下键盘鼠标或点击暂停即可取消；
  • 任意时刻都可以暂停 / 停止监控，停止即取消一切倒计时。

EzAway performs a local power operation — equivalent to pressing Start → Shut down, never force-closing apps — only after you deliberately start monitoring and it determines you have left the computer, continuously, for the duration you set. The determination is a weighted score over local Windows signals (display power state, session lock state, keyboard/mouse idle time, Windows' own user-presence state, and similar). If the keyboard or mouse saw any input within the last 5 seconds, EzAway always treats you as present and never starts a countdown. Monitoring starts only by your action; the UI permanently shows the current verdict and its reasons; a grace period (default 30 s) precedes any shutdown and is cancelled by moving the mouse or clicking Pause; you can pause or stop monitoring at any time.

3b. 判定信号（不做网络请求）

上述判定全部通过 Windows 自带接口在本机完成，不读取、不安装、不调用任何第三方或显卡厂商的组件。应用也不会向任何服务器询问您的位置或身份 —— 它只问本机「屏幕还亮着吗 / 会话锁了吗 / 键鼠多久没动了 / Windows 自己认为用户还在不在」。

All of the signals above are read locally through built-in Windows APIs. EzAway does not read, install, or invoke any third-party or GPU-vendor component, and never asks any server about your location or identity — it only asks the local machine whether the display is on, the session is locked, how long the keyboard/mouse have been idle, and what Windows itself reports about user presence.

4. 本地存储的数据

应用只把以下内容保存在您自己的电脑上（%LOCALAPPDATA%\EzAway）：

  • tray-settings.xml —— 您的监控时长、开关等设置；
  • logs\ —— 运行日志（仅本机排障用：状态变化、设置变更，不含任何个人内容）。

删除该文件夹即彻底清除全部数据，卸载应用同理。旧版写在安装目录旁的设置与日志会在首次运行时复制到新位置，原件保留。

Only your settings and local logs are stored on your own device under %LOCALAPPDATA%\EzAway. Delete the folder to erase everything; uninstalling does the same. Legacy files next to the old executable are copied (never moved) to the new location on first run.

5. 开机自启与系统权限

EzAway 不需要管理员权限，不安装驱动，不注册系统服务。可选的「开机自启」默认关闭：微软商店版通过 Windows 标准的启动任务（可在应用内开关，也可在「任务管理器 → 启动应用」中随时开关），直接运行的绿色版则写入您用户自己的 Run 注册表项，应用内可一键取消。界面上显示的开关状态一律以系统实际状态为准 —— 若该开关被系统策略锁定而未能生效，应用会如实显示未生效，不会显示成已开启。

EzAway needs no administrator rights, installs no driver, and registers no service. The optional autostart is off by default: the Store (MSIX) version uses a standard Windows Startup task (toggleable in-app or in Task Manager → Startup apps); the portable version writes to your own per-user Run registry entry, toggleable in-app. What the UI shows always reflects the actual system state — if the toggle is locked by system policy and did not take effect, EzAway shows it as not enabled rather than pretending otherwise.
